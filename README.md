# NeoStats Hackathon — Collaborative Project Management Platform

A multi-user collaborative project management platform built for the NeoStats Full Stack Engineering Hackathon.

## Tech Stack
- **Frontend**: React, Vite, React Router, Native fetch
- **Backend**: Node.js, Express.js, Mongoose, JWT, bcryptjs
- **Database**: MongoDB Community Server (Local)

## Project Structure
- `frontend/` - React client built with Vite
- `backend/` - Node.js Express REST API server
